Hearth is a household budget site for one family: a monthly dashboard (income vs spending, savings rate, spending by category), transactions with search, filters and add/edit/delete, category budgets with progress bars you can change, savings goals you can fund, recurring bills with due dates and paid tracking, and monthly reports with charts and plain-language insights. Demo data covers the Hartley household across August to November 2026, and everything you change is saved in your browser with localStorage — no account, no uploads, no network requests. The site is plain static files with no build step and no external libraries, and it works on a desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in a browser.
